# julianacubasvet.com.br

Site da Dra. Juliana Cubas, veterinária a domicílio em Tietê-SP. Feito pela [L R G Z](https://lrgz.com.br).

Estático, sem build: `index.html`, `assets/css/site.css`, `assets/js/site.js` (topo, menu, entradas, dúvidas, patinhas) e `assets/js/amora.js` (a Shih Tzu em pixel no fim das dúvidas). Fontes self-hosted em `assets/fontes` (Antonio, Jost, Mrs Saint Delafield). `tools/og.html` gera o `og.jpg` (captura 1200×630).
